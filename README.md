## Description 
> A service provider app created for local home cooks / caterers offering meal plans and hot meal drop offs. The app aims to help busy families, and professionals save time on cooking while also having tasty nutritious meals.
>
## App Functions
1. Customer (the user with the customer role):
    1. Create/modify customer profile - Register as a customer, set macronutrient                          requirements and dietary restrictions
    2. View available services - View available home cooks / caterers and previous meals they’ve made
    3. Subscribe to available services - Order one time meals or subscribe to a weekly meal plan option
    4. Write reviews for subscribed services - Leave reviews and ratings on home cooks and the meals they’ve cooked
